# Altrium Recruitment and Hiring Tracker

A web-based recruitment and hiring tracker developed for Altrium to support and organise the recruitment process.

## Project Overview

The Altrium Recruitment and Hiring Tracker provides authorised staff with a centralised system for managing recruitment activities. The system supports different user roles and provides role-specific access to recruitment information and functions.

## Main Features

- Secure user login
- Role-based access control
- Job position management
- Interview stage management
- Candidate management
- CV upload and storage
- Interview feedback management
- Candidate stage progression
- Hiring decision management
- Recruitment notifications
- Management dashboard and reporting
